Token Radar (radar-2): a peer-anchored ranking of 198 pre-token DeFi protocols by implied launch value, each with a five-step farm plan. Every value follows from the sealed DefiLlama snapshot — a protocol's TVL times its category's median market-cap-to-TVL ratio among live-token peers — adjusted for 7-day growth, age with no token, and chain breadth. See METHOD.md for the model and its limits.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input path/to/snapshot.json
```
